# 字体资源

使用小赖字体 Xiaolai v3.126 制作的 Pantry Hand WOFF2 分包，字形未改绘。
原字体作者、版权与 OFL 1.1 条款见 OFL-Xiaolai.txt；生产构建附带 public/licenses/OFL-Xiaolai.txt。

45 个字体分包通过 src/styles/handwriting.css 的 unicode-range 按需加载，只预载约 114 KB 的固定文案包。数量、日期和分数使用系统字体。

素材来源与转换过程保留于仓库 design/kitchen-journal-v1/assets/fonts/README.md，当前目录的 manifest.json 记录分包大小。正式应用不依赖原型目录运行。
