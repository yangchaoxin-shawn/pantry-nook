## 当前工作与下一步

- 用户已确认补充不属于正餐的日常库存消耗。本地开发分支 `codex/casual-consumption` 已实现“用掉了”数量弹窗、原子扣减、消耗与处理记录、安全撤销、幂等重试及 migration 015，并通过隔离 API、旧库迁移、前端测试、生产构建和桌面/窄屏双主题浏览器关键路径检查；待用户本地验收，当前尚未发布，生产仍为 `v1.2.0`。
- 已落地用户批准的协作改进：统一文档职责、设计与能力前置检查、持续改进、固定发布工具和新会话基线检查。后续任务“Pantry Nook 后续迭代”须使用本轮完整开发提交并回传实际核验结果，不能从旧 UI 分支继续。
- 下一轮依据用户真实使用反馈，先明确问题、影响范围和验收路径；已确认范围内完成修复与收尾，不反复请求同一许可。
- 新部署脚本的离线检查不等于服务器演练；下次获批发布前必须核验最新候选和服务器实际状态。本轮不重新部署、不变更产品版本/tag、不写生产数据。
- 持续改进遵循 [协作流程](collaboration.md#持续改进)：发生返工就定位原因，做小调整并验证；有效规则替换旧规则，避免无效流程积累。
