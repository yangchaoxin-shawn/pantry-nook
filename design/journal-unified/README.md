# 饭桌手记 · 系统 UI 一致性设计稿

2026-09-16。用户批准先评审独立设计稿，确认后再修改正式界面。本稿不连接 API、数据库或线上服务，所有新增、编辑、删除仅在浏览器内存中演示，刷新恢复示例。

## 本轮范围

- 页面骨架、标题区、按钮、功能字号、筛选、编辑删除、弹窗、提示和查看照片沿用系统视觉语言。
- 照片继续使用按数量变化的纸张拼贴，日期与文字建立记录节奏；支持评审 1—9 张、亮暗主题、桌面与手机布局。
- 菜品簿页签只提供视觉对照，导航仅显示本稿涉及的两个模块，不代表修改正式导航。
- 页头复用已批准的 `kitchen-team.webp` 与相片纸边框。没有另行生成新角色或拍照姿势插画；如后续需要专属插画，再基于本轮评审结论设计。

## 复用来源

直接只读引用 `frontend/src/App.css`、`styles/journal.css`、完整 `styles/handwriting.css`、`shared/ui/journal-scene-hero.css` 与 `features/journal/journal-page.css`。原型覆盖层只保存在本目录，不修改正式样式。色板以最后生效的 journal.css 为准；图标路径来自 `Primitives.tsx`。

原型依赖当前仓库中的这些共享文件，未来重启时应核对引用基线。私人测试照片仅由本机服务映射读取，不复制进仓库。

## 体验入口

默认本机地址：`http://127.0.0.1:5232/`。启动前先确认端口空闲；本稿与已有 5230/5231 正式功能测试服务互不改动。

```powershell
python design/journal-unified/serve.py --port 5232 --samples 'C:\Users\yangchaoxin\Downloads\素材'
```

- 顶部“评审选项”：切换空白、加载、错误状态与首篇照片数量。
- “记下一餐”或“编辑”：点图换封面、右上角移除、8 秒内撤销、替换照片。
- 弹窗内“设计稿体验工具”：加入示例、一次加入 12 张、模拟保存失败。
- 点击正文照片：大图查看、前后切换、缩略图、下载原片；支持 Escape 关闭、方向键与触摸横滑。
- 新建关闭后保留本页草稿；刷新后清空。编辑取消不更改示例原记录。

## 演示边界

原型可用本地 JPG/PNG/WebP 实际选图或拖入，并预览浏览器能解码的图片；文档与独立视频被拒绝。本稿没有 HEIC 转换服务，浏览器无法解码时会明确说明设计稿限制，正式系统的 HEIC 支持不变。原型 30 MB 读取限制仅用于本机演示，不定义正式上传约束。

没有实现真实上传进度、后端保存、文件持久化、并发或版本冲突；失败状态由评审工具模拟。设计稿检查不替代正式功能测试或真机验收。
