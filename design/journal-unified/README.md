## 当前评审方式

- 餐安排：展示真实线上截图，本轮保留原有标题、入口和空状态。核验时待做与历史均为空，有数据的时间线不计为本轮线上验证覆盖。
- 库存：真实线上头部与建议效果对照。适度放大插画，将原有单个／批量记录操作放到说明下，解决原型文字悬空；手机以操作与场景并排组织，清单与筛选沿用现有结构。
- 菜品：真实线上菜品簿与建议效果对照。调整菜名宽度、字号与小人占比，保留连续纸张、自然流排与不同姿态。手机截图捕获时隐藏悬浮导航，避免长截图遮住书页；不代表删除导航。
- 手记：保留可操作设计稿，复用系统字体、色板、按钮、弹窗和反馈。独立透明插画为小人拍摄煎饺、收藏饭桌照片，默认三篇手记使用五张不同测试照片。

旧模块不再维护完整模拟页面。截图是2026-09-17只读核验时的快照，不代表持续实时同步。建议效果通过同一线上页面的独立浏览器副本临时调整CSS和操作位置后截图，未修改服务器。具体事实见 [线上基准核验](../../docs/ui-review-online-baseline-2026-09-17.md)。

## 体验

- 顶部模块切换；旧模块支持桌面／手机对照，右上角切换亮暗主题。点击「打开原尺寸」查看截图。
- 手记「评审选项」切换正常、空白、加载、错误及首篇1—9张照片；其他模块中禁用。
- 录入／编辑支持点图换封面、右上角移除、8秒撤销、替换照片；新建关闭保留本页草稿，刷新恢复示例。
- 「设计稿体验工具」可加入3张或一次加入12张。超额挑选的计数与确认按钮固定在弹窗底部；仅内部照片区滚动。
- 多张竖照减少跨行空隙；手机大图切换按钮浮在画面边缘，保留完整照片空间。支持缩略图、方向键、触摸横滑与下载原片。
