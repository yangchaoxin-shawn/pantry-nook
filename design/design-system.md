# 食隅记 Pantry Nook · 设计规范 Design System

> 版本 2.0 · 2026-09-09
> 视觉唯一事实源：Ardot 画布 `fileId 723725203427240`（两屏：今日三餐 / 共享反馈墙）
> 可交互原型：`pantry-nook-prototype.html`（零依赖，双击即开）

---

## 1. 设计定位

**一句话**：一套属于 1-2 人家庭的厨房管理语言，从「记录食材 → 今日菜单 → 确认三餐 → 消耗归档 → 共享反馈」闭环。

**气质关键词**：温暖 · 居家 · 生活化 · 清晰高效（数据密集但保留烟火气）。

**三条不打破的规则**：
1. 单一强调色（陶土）贯穿全局，功能色仅做状态语义绑定。
2. 胶囊形 = 「行动」的唯一语法；所有按钮按压反馈统一 `scale(0.95)`。
3. 层级靠字重 + 灰度区分，不用 500 中间档；标题负字距。

## 3. 字体排印 Typography

**字体栈**：系统字体 `SF Pro Text / PingFang SC / Microsoft YaHei / system-ui`；标题 `SF Pro Display / PingFang SC`。

| 角色 | 字号 / 字重 / 字距 | 示例 |
|---|---|---|
| Display | 56 / 600 / -0.025em | Hero 主标题「在厨房一隅」 |
| H1 | 40 / 600 / -0.02em | 「今晚吃什么?」 |
| Title | 36 / 600 / -0.02em | 反馈墙页头 |
| Headline | 17 / 600 | 菜名 / 卡标题 |
| Body | 17 / 400 / 行高 1.47 | 正文 |
| Caption | 14 / 400 | 元信息 |
| Fine Print | 12 / 400 | 时间戳 / 说明 |

> 约定：不做 500 中等档，正文 400、强调 600/700，层级清晰不油腻。

---

## 4. 圆角与间距

**圆角**：工具按钮 `8px` · 输入框/行 `12px` · 卡片 `18px` · 胶囊/徽标/主按钮 `9999px`。

**间距单元**（4 的倍数）：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 80`。
卡片内边距 `24`，区块间距 `48`，页面左右留白 `32`。

**动效**：快 `150ms`、基准 `300ms`，`cubic-bezier(.4,0,.2,1)`。

## 5. 组件 Components

### 5.1 按钮 Buttons
- **btn-primary**：陶土渐变 `linear-gradient(180deg,#C4632A,#A34B1A)` + 内高光 + 阴影，白字。
- **btn-ghost**：透明底 + 1px 陶土描边。
- **btn-dark / btn-pearl / btn-danger**：深底 / 暖白底 / 危险描边。
- **disabled**：暖白底 + 淡字 + `not-allowed`。
- 统一：按压 `scale(0.95)`、聚焦 `outline 2px var(--primary)`。

### 5.2 状态标签 Badges
`badge-success / -warning / -danger / -info`，胶囊形 + 前置 5px 圆点，字体 12/600。

### 5.3 输入框 Inputs
高度 48，聚焦 = 陶土描边 `border-color:var(--primary)` + 3px 浅陶土光晕 `box-shadow:0 0 0 3px var(--primary-100)`。

### 5.4 用户模块（桌面导航右簇）
- **默认**：`userpill` 暖白胶囊（头像 40 + 名字 + chevron）。
- **展开**：`dropdown` 下拉卡（`dd-item`），含用户信息头、反馈墙入口（`hot` 高亮 + 未读角标）、家庭成员、口味偏好、设置、退出。
- **动效**：展开 `ddIn .18s cubic-bezier(.2,.8,.3,1)`，点击外部自动收起。

### 5.5 共享反馈墙
- **`fb-card`**：反馈卡，圆角 20，`unread` 浅陶描边 + 未读点，`read` 降透明度 0.65。
- **`ftag`**：反馈感受标签（很喜欢=绿 / 有点困惑=黄）。
- **`mood`**：移动端三态感受选择（很喜欢 / 有点困惑 / 想吐槽），`sel` 选中态陶土底。
- **`qtag`**：快捷标签。
- **`toast`**：提交后底部浮出「已发布到共享反馈墙」。

## 6. 关键页面

### 6.1 桌面端 · 今日三餐（1440×900）
- 顶栏：品牌 + 导航（今日/库存/菜品/反馈墙）+ 写反馈主按钮。
- 主标题「今天吃什么?」+ 副标题（三餐进度）。
- 左栏：今日菜单卡（三餐切换 「早餐·2 / 午餐·1 / 晚餐·3」 + 菜品行 + 确认状态）。
- 右栏四卡：库存 28 / 临期 3 / 优先吃掉它们 / 食材周转洞察（消耗 5.2 样、周转 4.1 天、废弃率 8%）。

### 6.2 桌面端 · 共享反馈墙（1440×900）
- 绿色共享标识「共享部署 · 无需登录，打开即见」。
- 写反馈入口（头像 + 输入卡 + 「很喜欢/想吐槽」快捷感受）。
- 三条反馈：早餐很喜欢 / 午餐困惑 / 晚餐已采纳（覆盖三餐）。
- 底部采集说明条「通过一个共享链接即可写入与查看」。

## 7. 产品模型：共享链接

**去账号化**：单链接部署，打开即见全部内容。谁都能写、看、采纳为待办、标记已读。无登录、无角色、无权限。

学习反馈闭环流程：**任一访客留言 → 家人进入同一链接 → 采纳为待办 / 标记已读 → 产品随生活迭代**。无需线下转述。
