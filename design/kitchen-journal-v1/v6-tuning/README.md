# 第六版：轻微减淡对照稿

2026-09-13。用户澄清：需要在第六版上淡一点，并非第七版的整体表面风格替换。本目录只供视觉对齐，未替换根原型或正式前端。

[打开 100%／75%／50% 对照](http://127.0.0.1:5194/v6-tuning/?v=3)。按用户本轮要求增加约 50% 档，并默认展示；顶部可即时切换 75% 和第六版原样。同一个 iframe 保留当前页面和输入，不因比较重新分配小人。

## 基线与唯一变量

- `baseline/` 的 10 个 CSS / JS 来自 Git `c94717f`。仅调整相对素材、方向页和说明链接路径；源文件 SHA-256 见 `baseline-manifest.json`。字体与图片复用父目录，避免重复复制大资源。
- `preview.html` 使用同一提交的页面骨架，增加对照样式及控制脚本，默认进入库存页。原色、形状、边框、阴影、字体与布局保持 V6。
- `tuning.css` 只降低纹理贡献：75% 档将原暖色遮罩 alpha 从 64/255 调到 112/255，背景纹理剩余对比约为原稿的 74.87%；50% 档调到 160/255，保留约 49.74%。不是降低整页透明度，也不降低文字或插画透明度。
- `grain-75.svg`、`grain-50.svg` 以原 WebP 字节和原 640px 尺度，分别设置 0.75、0.5 图层透明度；原纹理文件没有修改。因 CSS 自定义属性中的相对 URL 会随使用它的样式表解析，包装图使用当前 5194 站点内的绝对路径 `/v6-tuning/grain-75.svg`、`/v6-tuning/grain-50.svg`。
- `comparison.*` 是外围对照工具，不是产品 UI。三档切换互斥的 `tune-gentle` / `tune-half` 类，原样档移除两者；跨窗口消息校验 origin、来源窗口与档位枚举。

## 本轮增加 50% 的定向检查

- 1440×1000 桌面：50% 切换 75% 后，标题区尺寸、背景色、字体、阴影与圆角相同。
- 390×1000 手机：三档按钮可操作；75% 输入“番茄”后切到 50% 仍保留筛选；50% 亮暗主题目视检查通过。切回原样会移除减淡类。检查后清除输入、恢复浅色 50% 并重置视口。
- 浏览器实际样式使用 `grain-50.svg` 和暖色 alpha 160/255；子 agent 只读复核原图字节、约 50% 的计算与模式切换通过。
- 两个控制脚本 `node --check` 通过；`git diff --check` 通过。本轮不重跑业务或正式前端全量检查。
- 新对照页首开仍捕获一条无源文件的 MutationObserver 错误，与前轮同类，尚未定位来源；不宣称控制台全程零错误。三档切换、搜索与主题交互实际可用。
- 新截图：[桌面 50%](../evidence/v6-tuning/desktop-half.png) · [手机 50%](../evidence/v6-tuning/mobile-half.png)。纹理比例等待用户选择。
