# 第六版：轻微减淡对照稿

2026-09-13。用户澄清：需要在第六版上淡一点，并非第七版的整体表面风格替换。本目录只供视觉对齐，未替换根原型或正式前端。

[打开原样／稍淡对照](http://127.0.0.1:5194/v6-tuning/)。默认展示“稍淡一点”，顶部可即时切回“第六版原样”。同一个 iframe 保留当前页面和输入，不因比较重新分配小人。

## 基线与唯一变量

- `baseline/` 的 10 个 CSS / JS 来自 Git `c94717f`。仅调整相对素材、方向页和说明链接路径；源文件 SHA-256 见 `baseline-manifest.json`。字体与图片复用父目录，避免重复复制大资源。
- `preview.html` 使用同一提交的页面骨架，增加对照样式及控制脚本，默认进入库存页。原色、形状、边框、阴影、字体与布局保持 V6。
- `tuning.css` 只在稍淡档降低纹理贡献：原暖色遮罩 alpha 从 64/255 调到 112/255，背景纹理剩余对比约为原稿的 74.87%。不是降低整页透明度，也不降低文字或插画透明度。
- `grain-75.svg` 以原 WebP 字节和原 640px 尺度，设置 0.75 图层透明度；原纹理文件没有修改。因 CSS 自定义属性中的相对 URL 会随使用它的样式表解析，此包装图使用当前 5194 站点内的绝对路径 `/v6-tuning/grain-75.svg`。
- `comparison.*` 是外围对照工具，不是产品 UI。两档仅切换 `tune-gentle` 类；跨窗口消息校验 origin、来源窗口与档位枚举。

## 定向检查与边界

- 子 agent 精确比对：10 个基线文件只存在路径／换行适配，未混入 V7 色板或标题区；原图字节和 75% 参数正确。
- 1440×1000 桌面：切换两档后标题区的位置、尺寸、字体、背景色值、圆角和阴影完全一致，仅纹理变化。
- 390×1000 手机：两档按钮可操作；输入“番茄”后切换方案仍保留输入及筛选结果；已清除测试输入。亮色与暗色稍淡稿目视检查通过。
- 素材路径的首次定位问题已修正，浏览器实际样式指向正确的 SVG 包装图。
- 首开浏览器曾记录一条未带源文件的 MutationObserver 错误；本目录没有该调用。监听 Runtime 异常后重新加载未复现。来源尚未确定，不宣称本轮控制台全程零错误。
- 只验证独立对照页，不重跑业务、API、数据库或正式前端检查。尚未获得用户对减淡幅度的确认。
