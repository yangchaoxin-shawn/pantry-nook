## 本轮设计决定

第一版插画偏小、表面层次接近，操作后视觉反馈不足。本轮沿用已确认的业务边界，集中提升插画、材质和动态表现。

| 部分 | 第二轮设计 | 用意 |
|---|---|---|
| 主插画 | 原创粉彩 / 水粉食物静物：番茄、蛋碗、搪瓷锅、木勺、格纹布和微小人物 | 用食物肌理与生活细节建立记忆点 |
| 库存插画 | 独立菜篮、瓶罐、蔬菜和标签 | 库存页有自己的视觉内容，同时保留紧凑清单 |
| 菜品插画 | 食谱本、书签、餐盘与木勺 | 呼应菜品复用和常用搭配 |
| 材质 | 奶油纸纹、叠纸边缘、胶带、缝线、印章、格纹 | 拉开纸张、餐布和按钮的层次 |
| 标题 | 手写标题、黄油色下划线、小涂鸦箭头 | 增加手账感；数量和输入继续清楚可读 |
| 夜间 | 深绿纸面、浅色字；主插画保留为暖色剪贴画 | 维持对比度，同时保留食物本色 |
| 信息密度 | 装饰集中在页头、搭配便笺和分组边缘 | 库存条目继续只放名字＋数量；核对只有实际量可填 |

配色：纸底 `#F5EEDC`，卡片 `#FFF9ED`，主绿 `#52715B`，正文 `#334936`，次级文字 `#656D58`，陶红 `#98553E`，黄油色 `#E9D499`。

关键色对静态对比度：正文 / 纸底 8.45；次级文字 / 纸底 4.67；主按钮 5.17；陶红 / 纸底 4.90；暗色正文 / 背景 11.74。插画与装饰颜色不承担库存状态语义。

## 动效按操作区分

| 场景 | 动态反馈 |
|---|---|
| 主导航 | 选中块滑到目标入口，360ms |
| 页面与列表 | 纸卡进入视野时轻轻抬起，420ms，错开最多 180ms |
| 点击按钮 | 轻压、回弹，270ms；鼠标悬停轻抬起 |
| 首页插画 | 蒸汽缓慢流动；点击小锅时插画轻摇、涂鸦转动 |
| 弹窗 | 300ms 浮入、140ms 退出；内容切换轻移 180ms |
| 历史展开 | 内容轻移展开，240ms |
| 保存完成 | 对勾与提示条轻弹，430ms |

动画只影响展示。退出期间弹窗暂时不可再次操作，防止重复提交；同一表单增减条目保留滚动位置；筛选和导航重绘后恢复键盘焦点。

顶部提供“暂停动效”。系统开启 `prefers-reduced-motion` 时，CSS 和脚本动画一起停用，控件说明跟随系统。没有自动播放声音，也没有连续大幅度漂移。

- 仅修改独立原型与当前状态文档；没有修改正式 React 前端、API、数据库或业务规则。
