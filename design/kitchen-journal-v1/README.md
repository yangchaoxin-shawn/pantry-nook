## 打开

- 本次已启动的本地预览：[http://127.0.0.1:5194/](http://127.0.0.1:5194/)。
- 也可直接打开 [index.html](index.html)，让 preview.css 与 preview.js 保持在同一文件夹。无需安装依赖。
- 如果预览服务已经关闭，在本目录执行 `python -m http.server 5194 --bind 127.0.0.1`，再打开上面的地址。

本页是独立设计原型；没有请求真实 API，不存入数据库或 localStorage。内存数据刷新即还原。用户原有 3000 / 5173 服务和验收数据没有修改。

## 建议试看

1. 切换餐安排、库存、菜品，感受配色、留白和信息密度。
2. 库存点“冷冻”，只显示鸡胸肉；点食材进入详情。
3. 批量只填一行，保存；或填“大米、10、个”，查看同名与单位冲突弹窗。
4. 餐安排点“今天 · 午餐”的核对用料：胡萝卜库存 3 个、实际 4 个，需调整或跳去库存处理。
5. 把鸡蛋实际量改为 1/3，去处理胡萝卜库存，再返回核对；实际量保留。
6. “明天 · 晚餐”的菠萝尚未入库：补货后返回菜单，点明确的关联按钮，再核对。
7. 任意食材全部报废后，从库存页底部的全局处理记录进入撤销。
8. 顶部切换空数据、加载、读取失败；右上角切换亮暗主题。

复杂的并发、单位快照、安全撤销与取消恢复依然由正式应用承担；本页只验证设计呈现与列明的交互，不代替业务联调。
