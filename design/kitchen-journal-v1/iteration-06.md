# 第六轮：手写字、纸张与自动小人

2026-09-13。按用户反馈实施独立设计原型调整，待用户评审。[打开第六版](http://127.0.0.1:5194/?v=6)。

## 本轮设计取舍

### 字体

上一版依赖 Windows / macOS 本机楷体，偏规整，也不能保证不同设备一致。本轮引入 [小赖中文手写体](https://github.com/lxgw/kose-font)，使用本地 WOFF2 文件，标题、菜名和操作呈现自然字迹；数量、分数与日期继续用清晰的数据字体。实际浏览器字体信息已确认标题使用自定义 `Pantry Hand`，不是系统回退字体。

这是接近用户所指随性手写气质的选择，不声称找到喜茶官方字体。[字体版本、许可与加载说明](assets/fonts/README.md)。

### 纸张

重新访问 [Civa 参考原帖](https://www.xiaohongshu.com/explore/6a7ae50b0000000005030846)：正文可读，配图随后被站点安全限制。本轮没有绕过限制，改用首次研究保存在本机临时目录的第 02、09 张原图重新目视对照，旧索引见 [最初分析](analysis.md)。

参考是暖奶油色、细密颗粒与纤维明暗的纸面；并非只改一个背景色。本轮新生成纸张底图，替换规则网格和大颗粒划痕；控件使用透明纤维层，继承所在表面颜色。暗色继续使用深绿纸面，避免浅色纸图覆盖按钮后文字看不清。参考图片没有被复制为产品素材。

`assets/paper-v6.webp` 是页面底图，约 190 KB；`assets/paper-grain-v6.webp` 是透明纤维层，约 173 KB。背景底图有意不透明；前景人物均为透明 SVG。`prepare-paper.py` 从生成原图制备这两个文件。

### 自动插画

用户只需要输入菜名并保存。系统自动分配一位小人，不分析菜名，也不要求上传或挑选对应菜品照片。

1. 新增 24 种原创姿态：招手、伸懒腰、读书、坐着、拿花、气球、跳舞、散步、打盹、撑伞、击掌、平衡、风筝、滑板、听歌、拥抱、摘星、浇水、台阶、秋千、推圆球、云上休息、搬箱子、画画。
2. 打乱候选后逐个分配，同一轮 24 个不重复；候选用完后开始下一轮，有限素材不承诺永久不重复。
3. 同一菜品在重绘、切页、改名后保持原插画。餐安排中的相同菜名沿用它；常用搭配使用独立分配并在改名后保持。
4. 移除搭配卡片的“换张插画”步骤。页头的已认可食物拼贴继续保留；顶部样张库仅为设计评审，可比较 48 项素材，页头选择不进入新增菜品流程。
5. 挥手、道具轻动、秋千摆动、跳舞等短动作在出现或触摸时反馈；系统减少动态、页面暂停时停止，不持续循环抢占注意力。

小人属于视觉装饰，不是菜品内容、库存状态或真实照片。当前原型在内存中分配，整页刷新仍会还原；正式 React 接入时以稳定业务 ID 关联视觉映射，跨设备及刷新一致性留在正式接入阶段验证。本轮没有新增数据库图片字段或 API。

- 自动分配脚本：24 个姿态及首轮唯一、反复重绘、菜品／搭配改名、超过一轮后的继续分配、独立命名空间、装饰 SVG 检查通过。

- `preview.js`、`little-people.js`、`illustration-library.js` 语法检查通过；所查页面控制台 warning / error 为空。
- 两个素材制备脚本语法、45 个字体分包的格式头及体积、说明文档本地链接、`git diff --check` 通过。

最终截图及补充结果见 [预览说明](README.md)。这里只验证独立原型；没有重跑正式 typecheck / lint / build、真实 API、数据库、并发事务或 React runtime。当前页面不使用 React。
