# 设计预览 04 · 小厨房的拙趣日常

2026-09-13。用户已认可“拟真食物＋原创线稿小人”的方向，本轮将它应用到完整独立原型，待用户评审。正式 React 前端、API、数据库与业务规则未改。

## 这次的完整设计

以第三轮明确的拙趣插画为主，综合最初 Civa 参考中清楚的清单、厨房材质和操作层级。参考证据仍见 [插画研究](heytea-direction/research.md) 与 [第一轮分析](analysis.md)，本轮没有新增“已读取小红书原帖图片”的声明。

材质不是给页面换一个底色：

- 页面底层是细织纹、暖纸色和很轻的斜向光影。
- 内容纸面有可平铺的纤维纹理、柔和边缘与一层接触阴影；正文区保持低对比纹理。
- 菜单只留窄餐布边；常用搭配使用布面与线稿食谱。减少多层胶带和印章。
- 食物由拟真拼贴承担肌理，小人由不规则黑线承担动作与叙事。
- 夜间使用深绿纸底、低强度纤维和浅色插画纸片，文字切换为浅色；不直接反相食物图片。

## 每个位置怎么融入

| 位置 | 本轮实现 |
|---|---|
| 品牌与导航 | 手画锅标、略不规则轮廓、纸感选中块、移动滑块 |
| 餐安排 | 推番茄与搬鸡蛋的共同备餐场景；窄布边菜单，线稿食谱侧栏 |
| 库存 | 把胡萝卜搬进袋子的小人；类别手绘图标、紧凑纸面清单，名字＋数量 |
| 菜品 | 翻食谱与煎蛋拼贴；每行小型厨具线稿标记，不虚构菜品照片字段 |
| 常用搭配 | 餐布托住食谱／小锅线稿，名称、菜品与使用按钮分层 |
| 详情、录入、核对、冲突、恢复 | 统一纸面弹窗，按场景显示收纳／备餐／食谱／叶片小画；数量仍清楚可读 |
| 空态、加载、错误 | 翻书、等候、搬空盒、检查设备等不同场景；保留明确操作入口 |
| 保存与确认 | 成功后的小人短动作；变质处理用叶片，撤销处理用收纳场景 |

插画不会代替缺货、冲突和错误说明。手机库存每行实测约 48px，详情才展开次要信息。

## 动态与可操作性

- 点击三个页头可播放短动画。主图做轻微位移，首页附有小人动作；不会将静态拼贴称为人物骨骼动画。
- 导航滑块、按钮反馈、弹窗进入／退出、历史展开仍提供动态响应。
- 加载小人使用轻微、间隔式动作；保存与确认使用短反馈。
- 暂停开关停止 CSS 与脚本动画；系统减少动态效果同样生效。
- 表单输入、库存值与错误引导保持稳定，核对页不加入手动库存结余。
